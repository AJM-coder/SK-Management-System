# **BARANGAY SALAZA ANNOUNCEMENT MANAGEMENT SYSTEM**

    A web-based management system for Barangay Salaza to help Sangguniang Kabataan Officers manage public announcements for activities, events, and projects. This management system also helps Barangay Salaza Community to access public announcement for Sangguniang Kabataan.
    This platform aims to improves the information dissemination and providesorganized digital platform for managing SK operations.

## Features

    Officer Dashboard – Provides an overview of system activities and managing important information.
    Admin Dashboard - Provides an overview of system accounts, addition, updating, and deletion.
    Programs Management – Organizes and manages SK programs.
    Events Management – Handles event information and activities.
    Announcements – Displays public announcements and updates.

## Tech Stack

- **Frontend:** HTML, CSS, JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Development Environment:** XAMPP
- **Code Editor:** Visual Studio Code
- **Version Control:** Git and GitHub
- **Deployment:** InfinityFree

## Development Workflow

- **Phase 1:** Development of authentication pages including the login and logout pages.
- **Phase 2:** Development of dashboard pages for admin access and connection to database.
- **Phase 3:** Development of dashboard pages for officer access for post management.
- **Phase 4:** Development of public viewing dashboard. At the same time full database connection.
- **Phase 5:** Development of restriction for admin accounts.
- **Phase 6:** Finalization of version 1 of fully functioned system
- **Phase 7:** Adding additional changes in functions and designs.

## Deployment Step

- **Step 1:** Initialization of git as version control and development system that run locally using XAMPP Server.
- **Step 2:** Creation of GitHub Repository for project's source code and revision history tracker.
- **Step 3:** Choosing free web hosting service that supports php, and dynamic websites, which is the InfinityFree.
- **Step 4:** Creating hosting account for file and database management.
- **Step 5:** Uploading source code and connecting MySQL database.
- **Step 6:** Deployment and testing.
